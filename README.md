# Simple RNN-Based Sentiment Analysis

## Overview

This project demonstrates a text sentiment classification pipeline using a Simple Recurrent Neural Network (RNN) implemented with TensorFlow and Keras. It processes text sentences, converts words into numerical sequences, applies padding, and predicts whether a sentence expresses positive or negative sentiment.

The project is designed to understand the fundamental concepts of Natural Language Processing (NLP) and deep learning.

## Objectives

- Understand text tokenization and vocabulary creation.
- Convert text sentences into numerical sequences.
- Apply sequence padding to maintain consistent input dimensions.
- Learn word representations using an Embedding layer.
- Build and train a Simple RNN for binary classification.
- Generate sentiment predictions for unseen text.

## Technologies Used

- Python 3.12
- TensorFlow 2.21.0
- Keras
- NumPy

## Model Architecture

The model uses the following layers:

1. **Embedding Layer:** Converts token IDs into dense vector representations of dimension 8.
2. **SimpleRNN Layer:** Processes sequential information using 8 recurrent units and the `tanh` activation function.
3. **Dense Output Layer:** Uses one neuron with sigmoid activation to produce a probability for binary sentiment classification.

### Model Configuration

| Component | Configuration |
|---|---|
| Input sequence length | 4 tokens |
| Embedding dimension | 8 |
| RNN units | 8 |
| Output units | 1 |
| Optimizer | Adam |
| Loss function | Binary cross-entropy |
| Metric | Accuracy |
| Training epochs | 100 |

## Dataset

The project uses a small, manually created dataset containing 12 sentences related to food, service, and ambience.

Each sentence is assigned a binary sentiment label:

- `1` — Positive sentiment
- `0` — Negative sentiment

Examples:

| Sentence | Label |
|---|---:|
| food was good | 1 |
| food was bad | 0 |
| service was excellent | 1 |
| ambience was terrible | 0 |

This dataset is intended for educational experimentation and is not a representative real-world sentiment dataset.

## Workflow

1. Load the training sentences and labels.
2. Tokenize the text and create a vocabulary.
3. Convert sentences into numerical sequences.
4. Pad sequences to a fixed length of four tokens.
5. Calculate the vocabulary size.
6. Build the Embedding, SimpleRNN, and Dense layers.
7. Compile and train the model for 100 epochs.
8. Convert unseen sentences into padded sequences.
9. Generate sentiment probability predictions.
10. Classify predictions using a threshold of 0.5.

## Example Output

The prediction section displays information in this format:

```text
Sentence : <input sentence>
Sequence : <token sequence>
Prediction : <probability>
Sentiment : Positive / Negative
```

The probability is generated by the sigmoid output layer. The sentiment label is assigned using a threshold of 0.5.

Exact probabilities and predictions may vary depending on the training process and model initialization.

## Limitations

- The dataset contains only 12 training sentences.
- The model is intended for learning and demonstration, not production use.
- Unseen words may be mapped to the out-of-vocabulary token.
- Predictions have not been validated using an independent, labeled test dataset.
- The model may not generalize reliably to real-world reviews.
